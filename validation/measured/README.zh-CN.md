# 实测验证数据集：六个已发表工况

[ [English](README.md) | **简体中文** ]

本目录记录 Fintube HX 已对比过的全部公开实测数据：每个数字的出处、输入如何映射、比较结果，以及这些比较能证明到什么程度。**没有对这些数据做任何拟合**：没有调整换热/摩擦倍率、关联式系数或任何输入去凑实测容量。

- `cases.json`：来源（文献、DOI/网址、页码/表/图定位、所下载PDF的SHA-256）、边界条件、实测值、映射假设及全部计算结果。
- `inputs/`：两个水盘管工况可由 Community 直接运行的输入（整体几何模型）。
- `../../tools/run_measured_validation.py`：重算 Community 工况并打印对比；`tests/test_measured_validation.py` 保证可复现。

四个制冷剂工况需要真实逐管回路模型，该模型属于 Fintube HX Pro，**不在本仓库中**；其 Pro 结果仅为透明起见记录于此。原文PDF不在仓库中转发，请按下列链接获取。

## 3. 每项比较能区分什么

制冷剂工况的质量流量和入口状态是实测输入，容量在很大程度上已被边界条件锁定。无论空气侧模型是否准确，只要完成相变，计算容量必然落在下列区间内：

| 工况 | 容量区间（相变刚完成 … 出口达到进风温度） | 真正有区分力的量 |
|---|---|---|
| E1 | −8.8% … +1.3% | 过热度 |
| E2 | −8.9% … +1.9% | 过热度 |
| C1 | −6.3% … +8.6% | 过冷度 |
| C2 | −6.7% … +10.1% | 过冷度 |

因此E1/E2容量误差小**不能**作为空气侧准确的证据；冷凝器容量误差几乎全部来自缺失的过冷段（计算出口位于饱和液边界）。

## 4. 验收评估（v5）

判据：容量误差在 max(10%, 2×原文测量不确定度) 内，且仅在上表区间宽于该判据时计入；过热/过冷度在±2 K内；压降仅在实测区间与模型范围一致时比较。

| 工况 | 结论 | 主要原因 |
|---|---|---|
| W1 | **吻合**（−7.6%），边界不完整的参考工况 | 芯体风速未报告（见第5节） |
| W2 | **未达标**（−15.8%），保留为待解决 | 同一盘管、更高水量与风速；见第5节 |
| E1 | **吻合**（过热度−1.4 K；容量无区分力） | 百叶片按平片计算 |
| E2 | **未达标**（过热度−4.3 K） | 百叶片按平片计算 |
| C1 | **未达标**（过冷度−6.0 K） | 百叶片按平片计算；顺流过冷段 |
| C2 | **未达标**（过冷度−6.6 K） | 同C1 |

六个工况中两个满足上述判据。这是两台试件、六个工况的对比，不是产品精度认证。

**CETIAT假设性检查（不是计算结果）**：试件为百叶片，但原文没有给出百叶几何，因此只能用Wang–Chi平片关联式。若把所有单元UA统一乘以1.3（仅示意百叶类强化的量级，未拟合），过热度变为17.9/18.7 K（实测16.6/17.6 K），过冷度变为7.4 K（实测6.2/6.6 K），容量变化不超过+1.4%。实测出口状态介于平片与强化两种情况之间，说明主要原因是翅片型式替代。要建立百叶片关联式，需要从ICR 2019原文或制造方取得百叶间距/高度。

## 5. 水盘管（W1/W2）原因分析

来源中可确认的事实：

1. **风量口径。** Va是165×175 mm风道总截面的算术平均风速（学位论文第60页）。翅片迎风面（84.3×125 mm）只占37%，芯体/旁通分配没有报告。用论文Q_avg与学位论文有效度（图4.4，ε=0.132/0.108）反推的C_min流通面积为0.0270/0.0282 m²，风道为0.0289 m²，说明作者采用的是**整个风道**风量。v4、v5都令芯体迎面风速等于Va，这是最大的未解决边界假设。
2. **气流中的无翅片表面。** 每根管直段99.3 mm，其中翅片段84.3 mm；10根管由9个25 mm回弯连接，均位于风道内（期刊图2b；学位论文第41页）。v5用Churchill–Bernstein圆管横掠关联式、按Va计入这0.015 m²光管面积：W1 +26 W，W2 +37 W。
3. **实际片数。** 21片、片距4.23 mm，共20个片距、跨84.6 mm；原模型按“管长/片距”=19.9片。v5输入`geometry.fin_count = 21`；Wang关联式中的水力直径仍按周期通道计算，计入端片不会改变j/f。
4. **水侧回弯。** v5对每个回弯按Crane TP-410密排回弯（L/D=50）计入等效长度。3 L/min时计算4.61 kPa，学位论文实测5.24–5.40 kPa（图4.11），仅直管时为0.79 kPa。这是对回弯项的独立检验（不影响换热量）。

剩余偏差及其边界：

- 0.7–4.0 m/s范围内计算/实测比几乎恒定（对照学位论文图4.4：2 L/min为0.86–0.90，6 L/min为0.81–0.85），风速趋势吻合；偏差随水流量增大。
- 同一盘管的两份公开资料在试验1.3相差约7%（学位论文推算357 W，期刊333.5 W）。
- Wang–Chi（2000）平片j关联式本身对其数据库的描述能力为88.6%的数据在±15%以内。
- 敏感性（v5）：外露管风速±30% → ±1.2%；回弯半径取8 mm → −2%；芯体风速×0.8/×1.2 → W1 −16%/−0.3%，W2 −23%/−9%。
- 实测空气压降（学位论文图4.12：2.18 m/s时3.7 Pa、3.99 m/s时5.4 Pa）仅为芯体风速=Va时翅片芯体摩擦计算值（11.7/35 Pa）的约三分之一，表明存在旁通，即芯体风速**低于**Va，这会让计算值更低。该数据集的容量与空气压降无法用同一芯体风量假设同时吻合；原文也没有分别公布Q水和Q气。

结论：W1吻合；W2保留为待解决。两个水盘管工况作为“边界不完整的参考工况”保留，不作为容量精度的验收工况。要做定量水盘管验收，需要密封风道、分别报告Q水与Q气的实测数据。
