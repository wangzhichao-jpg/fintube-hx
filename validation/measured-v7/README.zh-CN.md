# 实测验证数据集 v7（内部验收集，公开事实与结果）

v7 = v6 的全部数据集，按需求规范 v1.2 的 F2～F4 重新判定。容差、归类规则和指标状态规则在运行前写定（2026-10-23T04:25:00Z），运行后不改。计算用的是专业版 0.7.0.dev1（v1 压降口径），共享核心 0.1.0.dev17。逐管流路输入属于专业版，不在本仓库发布，单靠开源核心无法复现这些数值。

## 判定规则

- **容差（F3）：** 换热量 ±5%；空气压降干工况 ±15%、湿工况 ±20%；冷媒压降（同口径）±25%。
- **归类（F4）：** 拒绝 → 外推 → 降级 → 口径不一致 → 计入，按此顺序判定。只有“计入”的点进入通过率；其余单列公开。
- **状态（P1）：** 计入点数 ≥ 1 且通过率 ≥ 90% 为“达标”；低于 90% 为“未达标”；没有计入点为“无证据”。三种状态都不阻止发布，但必须如实公开。

- **谭爱华 2015**（62 台，计入）：换热量平均偏高 3.9%，±5% 内 43 台。
- **CETIAT 2021**：几何超出 Wang 1999 样本 0.4%，按声明容差计算，属于外推，单列。Q 20/20 在 ±5% 内；SH 11/12 在 ±3 K 内；SC 2/8 在 ±2 K 内。
- **Joppolo 2015**（11 排）：按产品路径声明排数外推。3 个工况算出结果，压降 6/6 在 ±25% 内；另 3 个工况第 6 排局部值超过 1 排值，被产品拒绝。
- **Batista 2022**：超出全部平片关联式范围，被拒绝。
- **CETIAT 端部压降诊断：** 冷凝的超出量（12.8～18.8 kPa）用附件模型加液柱静压上限，最多只能解释 27%～36%。
